ChillPOS — Linux
================

Co 2 cach chay tren Linux:

A) Portable unzip-and-run (khuyen dung cho may quay / offline)
-------------------------------------------------------------
1) Tai dung chip:
   - x86_64 / amd64 ........ ChillPos_POS_Release_linux_x64.zip
   - ARM64 / aarch64 ....... ChillPos_POS_Release_linux_arm64.zip
2) Giai nen vao ~/ChillPOS (KHONG dau cach trong duong dan).
3) Chay:

   cd ~/ChillPOS
   chmod +x ChillPOS-Start.sh ChillPOS-Stop.sh start.sh stop.sh allow_lan.sh
   ./ChillPOS-Start.sh

4) Mo http://127.0.0.1:8999
5) Tat: ./ChillPOS-Stop.sh

Yeu cau he thong:
- glibc 2.28+ (Ubuntu 20.04+, Debian 10+, RHEL 8+, Fedora gan day)
- Cong trong: 8999 (web), 9990 (PHP), 33306 (MySQL)

LAN (tablet / bep):
  ./allow_lan.sh
  ./ChillPOS-Stop.sh && ./ChillPOS-Start.sh
  Mo IP LAN:8999 tren thiet bi khac (khong dung 127.0.0.1)

In an:
  Khong co USB printer-bridge Windows.
  Dung network_tcp (may in LAN) hoac browser_bridge.

B) Docker Compose (server / da quen Docker)
-------------------------------------------
1) Cai Docker Engine + Compose.
2) Lay source co Dockerfile + docker-compose.yml + .env.docker.example
3) Cau hinh:

   cp .env.docker.example .env.docker
   # Doi MYSQL_ROOT_PASSWORD, DB_PASSWORD

4) Start:

   docker compose up -d --build

5) Mo http://127.0.0.1:8088  (port mac dinh compose; xem .env.docker)
6) Health: http://127.0.0.1:8088/health  → status=ok

Dung:

   docker compose down

Luu y Docker:
- Doi mat khau DB truoc khi public.
- Khong dung mat khau mau ChangeMe* tren production.
